# Sunday Pusoy Club — latest Vercel package
Includes online rooms, computer seats, portraits/table, winner celebrations, room Share invite and Table chat.

## Deploy from your computer
1. Extract this ZIP into a folder.
2. Open that folder in VS Code and open its terminal.
3. Run `npx vercel login` and finish sign-in.
4. Run `npx vercel --prod`.
5. Choose your Vercel account/team and the project `sunday-pusoy-club` (create it if absent). Use the included project settings.

The deployment provides the frontend and API proxy on Vercel. Its persistent online room service continues to run at https://sunday-pusoy-club.spastores70.chatgpt.site. Keep that backend public and running.

Share invite uses the native sharing menu where supported, with a copy-link fallback. A direct Facebook friend picker is not connected.
